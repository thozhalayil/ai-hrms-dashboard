# 🤖 AI-HRMS Dashboard

An AI-powered Human Resource Management System built as a **single-page web application** with 31 modules. Designed to simulate enterprise-grade HR operations — from talent acquisition to compliance — entirely in the browser with no backend required.

🔗 **[Live Demo](https://thozhalayil.github.io/ai-hrms-dashboard/HRMS.html)**

---

## 📸 Overview

Built with vanilla HTML, CSS, and JavaScript. Uses Chart.js for data visualizations and integrates PDF.js, Mammoth.js, and SheetJS for document processing — all client-side.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Charts:** Chart.js 4.4.1
- **Document Processing:** PDF.js, Mammoth.js (DOCX), SheetJS (XLSX)
- **Hosting:** GitHub Pages
- **Architecture:** Single-file SPA — zero backend, zero dependencies to install

---

## 🚀 How to Run

No installation needed. Just open the live demo or clone and open locally:

```bash
git clone https://github.com/thozhalayil/ai-hrms-dashboard.git
cd ai-hrms-dashboard
# Open HRMS.html in your browser
```
